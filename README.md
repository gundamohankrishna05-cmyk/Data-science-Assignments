# Data Science Assignments

Welcome to the **Data Science Assignments** repository! This repository contains a structured collection of Jupyter Notebooks covering essential Machine Learning, Deep Learning, and Advanced Analytics topics, progressing from classic algorithms to advanced sequential modeling.

## 🚀 Repository Contents

The repository covers a wide spectrum of data science implementations, structured as follows:

| Assignment | Topic | Key Concepts Covered |
| :--- | :--- | :--- |
| **Assignment 10** | Support Vector Machines (SVM) | Hyperplane optimization, linear/non-linear kernels, classification. |
| **Assignment 11** | Decision Trees | Entropy, Information Gain, Gini Impurity, tree pruning. |
| **Assignment 12** | Random Forest | Bagging, ensemble learning, feature importance, variance reduction. |
| **Assignment 13** | XGBoost & LightGBM | Gradient boosting framework, hyperparameter tuning, speed optimization. |
| **Assignment 14** | Principal Component Analysis (PCA) | Dimensionality reduction, variance retention, feature transformation. |
| **Assignment 15** | Clustering Analysis | Unsupervised learning, K-Means, Hierarchical clustering, Silhouette scores. |
| **Assignment 16** | Recommendation Systems | Collaborative filtering, content-based filtering, matrix factorization. |
| **Assignment 17** | Time Series Analysis | Forecasting, ARIMA/SARIMA, seasonality, trend detection, stationarity. |
| **Assignment 18** | Neural Networks | Multi-Layer Perceptrons (MLP), backpropagation, activation functions. |
| **Assignment 19** | Natural Language Processing (NLP)| Tokenization, TF-IDF, Word Embeddings, text classification. |
| **Assignment 20** | Recurrent Neural Networks (RNN) | Sequential data, LSTMs/GRUs, time-series/text generation sequence processing. |

## 🛠️ Getting Started

### Prerequisites
Make sure you have Python 3.x installed along with the following primary libraries:
* `numpy`
* `pandas`
* `scikit-learn`
* `xgboost`
* `lightgbm`
* `statsmodels`
* `tensorflow` / `keras`
* `nltk` / `spacy`
* `matplotlib` / `seaborn`

### Installation
1. Clone this repository:
   ```bash
   git clone https://github.com
   ```
2. Navigate into the project directory:
   ```bash
   cd Data-Science-Assignments
   ```
3. Open Jupyter Lab or Jupyter Notebook:
   ```bash
   jupyter notebook
   ```
